# Agent Simulation – Module 1 (Core)

Mobile-first multi-agent system.  
You control the **Boss**. The Boss controls the other agents.

## What you have right now

- **Boss Agent** → You give it orders
- **Banker Agent** → Manages money
- **InfoFarmer Agent** → Farms information
- Shared memory & task system
- Simple farm/Sims + Fallout-style mobile UI
- Fully modular structure (ready for more modules)

## How to run (easiest ways)

### Option A – Free cloud (recommended for phone)
I will help you deploy this for free later (Render, Railway, or similar free tier).  
Then you just open the link on your S25 Ultra.

### Option B – On a laptop (when you have one)
1. Install Python 3.10+
2. Open terminal in this folder
3. Run:
   ```
   pip install -r requirements.txt
   python main.py
   ```
4. Open browser to: http://localhost:8000
5. On your phone (same Wi-Fi): http://YOUR-LAPTOP-IP:8000

### Option C – Later on Android (Termux)
Possible but more advanced. We can do this if needed.
